================================================================================
FILTERING PIPELINE
================================================================================

applyFiltersAndSort must apply in this order:
1. activeTag filter (single tag clicked on a card)
2. searchTerm filter (debounced 300ms, matches against project name)
3. wallet multi-select filter (tags contain selected wallet names)
   Special: "Direct Wallet" means project has NO wallet tag matching WALLETS list
4. category multi-select filter (tags contain selected category names, case-insensitive)
5. token single-select filter (tags contain token name, uppercase comparison)
6. sort: DATE_DESC / DATE_ASC / NAME_ASC / NAME_DESC
7. pagination: slice by currentPage * projectsPerPage (options: 10, 25, 50)
