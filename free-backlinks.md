# Free Backlink Opportunities for TTEarnCrypto / iCryptos Dashboards

Researched for a crypto and web3 software directory, review aggregator, AI tool index, and
dashboard hub. Target properties:

- Brand: TTEarnCrypto ( iCryptos Dashboards )
- Canonical: https://ttearncrypto.com/dashboards/
- Niche: crypto and web3 software directories, reviews, AI tool indexes, dashboard hubs

## How to read this table

| Column | Meaning |
| --- | --- |
| Site / Platform | Where the link can be placed |
| URL | Signup, submit, or claim page |
| Category | Link bucket |
| How to get the free link | The actual action required |
| Link type | Expected rel value. "nofollow" is normal and still passes crawl equity |
| Cost | Free means no payment, no paid placement |
| Difficulty | Time to live. Quick is under a day, Medium is a few days, Slow can take weeks |

Do not expect every platform to link to the homepage. Where a platform has a directory or
category page, link the most relevant page instead. For this project that is usually
`/dashboards/`, `/reviews/`, or `/news/`.

## 8. Priority action plan

Ordered by expected value per hour of effort.

1. **Business listings, day 1.** Google Business Profile, Bing Places, Apple Business
   Connect, Yelp, Yellow Pages, BBB. These give a consistent citation across the web and
   support entity trust.
2. **Social profile completeness, day 1 to 2.** LinkedIn company page, X, Facebook page,
   Instagram, YouTube, TikTok, Pinterest, Bluesky, Telegram, Discord. Fill every profile
   field including the website, then link the profiles from the site footer.
3. **Publishing platforms, day 2 to 4.** Medium, Hashnode, dev.to, Substack, Blogger,
   Write.as, Telegraph. Publish two genuinely useful articles that link to `/dashboards/`.
   Request a custom domain on Hashnode or Medium for a stronger dofollow.
4. **Developer and open source presence, day 3 to 5.** GitHub profile README, GitHub
   Pages mirror, npm or PyPI package if applicable, CodePen, CodeSandbox, Kaggle.
5. **Startup directories, week 1 to 2.** Product Hunt, Indie Hackers, BetaList, Peerlist,
   Crunchbase, Uneed.
6. **Crypto specific, week 2 to 4.** CoinMarketCap, CoinGecko, CryptoRank, AlternativeTo,
   Capterra, Zealy, Mirror.xyz, ENS.
7. **Community and editorial, ongoing.** BitcoinTalk, Reddit, Quora, Discord, Telegram,
   Hacker News. Only participate where the link is a genuine answer to the question.

## Measurement

- Track referring domains, not raw link count. A new referring domain matters more than ten
  links from one domain.
- Record for every submission: platform, date submitted, URL of the live link, follow or
  nofollow, and whether it is indexed.
- Recheck live links monthly. Directories get pruned.
- Use Search Console to confirm that submitting platforms can crawl the site.
- Expect a lag of several weeks before new referring domains affect rankings.

## Avoid these

- Paid link packages, PBNs, link farms, and "500 backlinks for 20 dollars" services.
- Comment and forum link drops. They are usually removed and carry a spam signal.
- Auto posting the same description to dozens of aggregators. It reads as machine
  generated and gets ignored.
- Reciprocal link schemes arranged between unrelated sites.
- Creating fake accounts to post in communities you do not belong to.
- Exact match anchor text on every placement. Mix branded, URL, and generic anchors.
- Thin guest posts on sites with no real traffic or moderation.

## Verification note

Policies, field names, and approval rules change without notice. Confirm the current
submission flow on each platform at the time you sign up, and treat the "Link type" column
as an expectation rather than a guarantee. Anything marked Slow depends on human review and
cannot be automated or forced.
